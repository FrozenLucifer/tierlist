# Локальные инструменты проекта

| Инструмент | Назначение |
|---|---|
| `python -m tierlist_app` | Запускает локальный сайт для составления тир-листа. |
| `python -m unittest discover -s tests -v` | Проверяет хеширование, синхронизацию, рейтинг, удаление и откат без запуска браузера. |

Новых служебных скриптов в проекте нет: запуск и проверка выполняются через модуль приложения и встроенный `unittest`.
