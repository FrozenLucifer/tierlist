# Тир-лист объектов

Универсальное офлайн-приложение для парных сравнений любых объектов (книг, фильмов, игр и т.д.). Полностью клиентская версия — данные хранятся в IndexedDB браузера, сервер не требуется.

## Возможности

- **Объекты с названием, описанием и картинкой** — описание поддерживает гипертекст (`<a href>`, `<b>`, `<i>` и т.д.), ссылки открываются в новой вкладке
- **Без картинки — просто текст** — объект отображается как текстовая карточка
- **Добавление объектов**: загрузка картинок (множественный выбор), импорт из текста (каждая строка — отдельный объект), ручное добавление
- **Парные сравнения** — модель Bradley–Terry, рейтинг пересчитывается после каждого выбора
- **Отмена последнего действия** (клавиша Z)
- **Рейтинговая таблица** с неопределённостью
- **Экспорт / импорт** в `.tierl` (ZIP-архив с данными и картинками): сохранить с сравнениями или без, открыть файл (заменяет текущий тир-лист)

## Запуск локально

Просто откройте `index.html` в браузере. Никакой установки не требуется.

## GitHub Pages

Сайт разворачивается на GitHub Pages через GitHub Actions при каждом пуше в ветку `main`.

После включения Pages в настройках репозитория сайт будет доступен по адресу:
`https://<пользователь>.github.io/<репозиторий>/`

## Хранение данных

Все данные хранятся локально в IndexedDB браузера. Они привязаны к конкретному браузеру и устройству. Для переноса на другой компьютер используйте экспорт в `.tierl` и последующий импорт.
